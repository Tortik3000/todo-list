### Запуск

```shell
  docker compose up -d
```

После успешного запуска приложение будет доступно по адресу:  
**http://localhost:8080**

Чтобы изменить порт приложения, создайте файл `.env` на основе шаблона: [`.env.example`](.env.example)


### Структура проекта
*   `docs/` — содержит сгенерированную документацию Swagger. 
*   `tools/` — файлы для тестирования запросов к API.
