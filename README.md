# Todo List 

---

### Запуск бинарника
```shell
  make build
  ./bin/todo-list
```

После запуска приложение будет доступно по адресу:  
**http://localhost:8080**

### Запуск в докере

```shell
  docker compose up -d
```

После запуска приложение будет доступно по адресу:  
**http://localhost:8080**

Для запуска необходимо установить переменные окружения в  [.env](.env) 

.env:

```.evn
PORT=8080       - на этом порту приложение слушает запросы
LOCAL_PORT=8080 - на этом порту приложение доступно на вашей машине
```
